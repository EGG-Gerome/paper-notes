# 学习的文章

公开仓：[EGG-Gerome/paper-notes](https://github.com/EGG-Gerome/paper-notes)。只放文献笔记，**没有周报、病例、筛药数字**。

本地常放在 `lzt_tmp/docs/学习的文章/`，和私有周报仓并排，但是两个 Git 仓。

一篇一文一个文件夹：`YYYY-MM-DD_第一作者年份_期刊_关键词/`。

每个文件夹固定三块：

| 文件 | 放什么 |
| --- | --- |
| `原文/` | 能拿到的 PDF（Science 付费则放 PMC 作者稿 + DOI） |
| `学习心得.md` | 读完之后记住的机制、数字、边界 |
| `路线.md` | 这篇在文献链上的位置、建议先读/后读什么；**不是**项目工程路线 |

周报里只写「哪天读了哪篇」，细节以本目录为准。
