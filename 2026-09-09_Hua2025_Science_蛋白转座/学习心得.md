# 学习心得 — Protein editing using a coordinated transposition reaction（用协同转座反应做蛋白编辑）

> 2026-09-09 读。正文按 PMC 作者稿核对。正式版 doi:[10.1126/science.adq8540](https://www.science.org/doi/10.1126/science.adq8540)。

## 汇报口径

1. Protein editing using a coordinated transposition reaction（用协同转座反应做蛋白编辑）：
我读了 Science 2025 的 Protein editing using a coordinated transposition reaction。做的是已折叠蛋白上的内部替换。
传统半合成是碎片先连再折，折叠精度要求高，大蛋白失败率高。这篇在已折好的受体上预装一对正交 split intein（内含肽的两半，互不认错对象），再用供体片段把中间那段换掉：两半 intein 配对后把自己剪掉，两侧外显肽接成一条。
基本单元是：链1 = N-extein + IntN，链2 = IntC + C-extein，碰上再剪，得到 N-extein 接上 C-extein。蛋白连接、半合成里用得上（可盈的蛋白设计不知道行不）；对我现在的筛药研究帮助不大，当知识点。

## 一句话

传统半合成是「碎片先连再折」；本文是在**已经折好**的受体蛋白上，用一对正交 split intein 做一次「剪开 → 塞入供体片段 → 接上」。能用，是因为两对 intein 的结合/剪切速度配平了，走协同路径，少出半剪中间体。

## 几个词

- **PMC**：PubMed Central，NIH 免费全文库。`原文/` 里那份 PDF 是作者稿，不是杂志社排版。
- **recipient / 受体**：已经折好、中间预装了 intein 的那条蛋白，被改的那一方。
- **donor / 供体**：要塞进去的那段多肽（两边带着互补 intein）。论文里也叫 transposon。不是献血那个 donor。
- **DNA 转座**：基因组里一段 DNA 被剪下来、贴到另一个位置（转座子 / jumping gene）。论文只是借这个「剪开再贴上」的样子，对象是蛋白不是 DNA。

## 和传统半合成的差异（论文 Fig. 1）


|      | 传统（先连后折）          | 本文（原位转座）                     |
| ---- | ----------------- | ---------------------------- |
| 操作对象 | 三段及以上多肽碎片         | 已折叠的 recipient（可含多亚基复合物）     |
| 内部修饰 | 多次连接 + 纯化，收率叠乘下降  | 一次操作替换内部一段                   |
| 折叠   | 拼完必须再折；大蛋白/复合物常翻车 | 在天然折叠条件下 cut-and-paste       |
| 前提   | 要能做出两侧重组片段        | **基因里必须预先嵌好一对 split intein** |


论文自己写：内部修饰历来难，是因为要三块以上片段；侧翼重组段往往折不成、不好收；拼完还要再折。先前同实验室 tandem PTS 收率一般；Pless 等在爪蟾卵母细胞里成对 intein 改离子通道，估计收率 **<5%**。本文要解决的就是把两对 intein 配平，让转座能用。

## 关键不是「有 intein」，是动力学配平

两条路径：逐步（一对先剪完）vs 协同（两对同时结合再剪）。逐步会堆积半剪中间体，那些就是受体被拆开的碎片，容易错误折叠。

模型：MBP 与 eGFP 之间夹一对正交 intein（中间短 linker + TEV 切点），1:1 混供体片段。N 端用短 IntN 的非典型 split（Cat 或 VidaL），C 端用典型 Cfa。


| 配对              | 同位素实验读出            | 含义                 |
| --------------- | ------------------ | ------------------ |
| VidaL / 野生型 Cfa | 四种质量峰约 **2:1:1:2** | 协同 + 逐步混着走，半剪中间体明显 |
| Cat / mut-Cfa   | 几乎只剩两种均一标记峰        | 几乎全走协同             |


mut-Cfa = CfaN **M75L + M81L**，故意把 Cfa 剪慢一点，去对齐 Cat。后续工作都用 **Cat / mut-Cfa**。反应物比例对这套配对影响不大。

## 论文做了什么


| 体系                    | 位点                              | 塞进去的东西                                    | 功能读出                                                                                            |
| --------------------- | ------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------- |
| eGFP                  | 表面 loop **174–175**（还有 158–159） | HA                                        | 发射谱不变 → 反应过程中还折着                                                                                |
| eGFP                  | β-sheet **124–125**             | —                                         | **错误折叠，转座变差**。不是任意位点                                                                            |
| G9a                   | IDR **161–208**                 | HA                                        | 无序区适合嵌装置                                                                                        |
| dCas9 ~160 kDa        | 中间 loop **573–574**             | HA；再换成 **PEG12**                          | 预装 His 后仍能结合靶 DNA；PEG12 产物反向镍柱纯化，仍能结合互补 gRNA 的 DNA                                              |
| ACF（SMARCA5 ~120 kDa） | 用装置替换 APB 基序 **KRERK**          | 把 APB 塞回去；或带 **pTyr742**；或带 **photo-Met** | 复合物仍完整。塞回 APB = 重塑「开」；pY742 让滑动变慢（EMSA，n=5，P≤0.001；λPP 去磷后恢复）；photo-Met 交联组蛋白 H2A，过量 LANA 肽可竞争掉 |
| HEK293T               | 核内 / 活细胞共表达                     | HA→FLAG                                   | 核内 30 min 可见转座；活细胞共表达也出产物                                                                       |


论文用语是 **traceless** 装标签：装置被剪掉，换成 cargo。还要 **2–4 个有利 extein 残基** 在剪切接头两侧。

## 对照 CRISPR（理解用）

论文类比的是 **DNA 转座**，不是 CRISPR。对照是为了记住边界：


|       | CRISPR（DNA）       | 本文（蛋白）                           |
| ----- | ----------------- | -------------------------------- |
| 对象    | DNA               | **已折叠蛋白**                        |
| 要不要预装 | 直接送 Cas/sgRNA     | **必须先在蛋白基因里嵌好 intein 装置**        |
| 位点    | 几乎任意（有 PAM/sgRNA） | **只能在预装位置**；还要 2–4 个有利 extein    |
| 适合区域  | 基因组               | 表面 loop、linker、IDR；β-sheet 已证明翻车 |


这是蛋白半合成的切口，不是随心所欲的蛋白 CRISPR。
